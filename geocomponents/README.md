# geocomponents

geocomponents turns YAML descriptions of geographic datasets into PostGIS tables and OGC APIs.
Describe datasets and collections once and get a functioning geoservice for reading and writing data.

Currently only supports simple features.

## Get started

Follow [Create your first dataset](docs/tutorials/first-dataset.md) to start PostGIS and the API locally, create a collection, and write and read a feature.

## Documentation

The [documentation](docs/README.md) points to tutorials, how-to guides, explanation and technical reference of how the system is built.
